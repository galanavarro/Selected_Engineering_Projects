# Selected Engineering Projects

A portfolio of projects developed during my double degree in Biomedical Engineering and Industrial Electronics and Automation Engineering at Universidad Politécnica de Cartagena, including coursework completed during my Erasmus exchange.

The collection brings together hardware, software and simulation, from physiological signal acquisition and electronic circuit design to industrial interfaces and mechanical assemblies.

## Projects

| Project | Focus | Tools |
|---|---|---|
| [PPG Sensor Acquisition](./ppg-sensor-acquisition/) | Red and infrared PPG acquisition and signal visualisation using a pulse-oximetry sensor. | Arduino, MAX30102, I²C |
| [Biomedical Signal Analysis](./biomedical-signal-analysis/) | Sampling, aliasing, digital filtering and ECG analysis, including peak detection and heart-rate estimation. | Python, NumPy, SciPy, Matplotlib |
| [Cardiac Pacemaker Simulation](./cardiac-pacemaker-simulation/) | Circuit-based simulation of pacemaker stimulation and cardiac cell models. | TINA-TI |
| [Industrial Monitoring Interface](./industrial-monitoring-interface/) | Graphical equipment monitoring with multithreaded communications, operating-state indicators and timestamped data logging. | C++, Qt, OPC UA, ROS2 |
| [Impedance-Adapter PCB](./impedance-adapter-pcb/) | Schematic capture, PCB layout, routing and physical board construction. | DipTrace |
| [Claw Machine CAD](./claw-machine-cad/) | Mechanical modelling of a claw machine, including its supporting structure, gripping mechanism and lifting assembly. | SolidWorks |
| [Skin-Lesion Classification](./skin-lesion-classification/) | Guided image-classification projects covering CNNs, transfer learning, data augmentation and model evaluation. | Python, PyTorch, ResNet50 |

## Repository Guide

Each project folder contains its own README describing the objectives, technical content and available files. Depending on the project, these include source code, notebooks, circuit models, CAD assemblies, reports and visual results.

Individual and team projects are identified in their respective documentation. Third-party code and libraries retain their original attribution.
