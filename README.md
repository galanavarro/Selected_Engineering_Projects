# Selected Engineering Projects

A portfolio of projects developed during my double degree in Biomedical Engineering and Industrial Electronics and Automation Engineering at Universidad Politécnica de Cartagena, including coursework completed during my Erasmus exchange.

The collection brings together hardware, software and simulation, from physiological signal acquisition and electronic circuit design to industrial interfaces, mechanical assemblies and machine learning.

## Projects

| Project                                                               | Technical focus                                                                                                                               | Tools                            |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| [PPG Sensor Acquisition](./PPG_Sensor_Acquisition/)                   | Red and infrared PPG acquisition, serial recording and signal visualisation using an optical sensor.                                          | Arduino, MAX30102, I²C           |
| [Biomedical Signal Analysis](./Biomedical_Signal_Analysis/)           | Sampling, reconstruction, aliasing, digital filtering and ECG analysis for heart-rate estimation.                                             | Python, NumPy, SciPy, Matplotlib |
| [Cardiac Pacemaker Simulation](./Cardiac_Pacemaker_Simulation/)       | Circuit-based simulation of pacemaker stimulation and electronic cardiac-cell models, including transient response and parameter sensitivity. | TINA-TI                          |
| [Industrial Monitoring Interface](./Industrial_Monitoring_Interface/) | PLC-connected graphical monitoring and control, multithreaded communications, equipment visualisation and timestamped data logging.           | C++, Qt, OPC UA, ROS2            |
| [Impedance-Adapter PCB](./Impedance_Adapter_PCB/)                     | Schematic capture, component placement, PCB routing, physical board assembly and soldering.                                                   | DipTrace                         |
| [Claw Machine CAD](./Claw_Machine_CAD/)                               | Mechanical part and assembly modelling, integrating the supporting structure, gripping mechanism and lifting assembly.                        | SolidWorks                       |
| [Skin-Lesion Classification](./Skin_Lesion_Classification/)           | Guided CNN and transfer-learning projects covering image preprocessing, augmentation, training and quantitative evaluation.                   | Python, PyTorch, ResNet50        |

## Repository Guide

Each folder contains a dedicated README describing the project, technical approach, available files and execution or inspection instructions.

Depending on the project, supporting material includes source code, Jupyter notebooks, editable circuit models, CAD parts and assemblies, technical reports and visual results.

Individual and team projects are identified in their respective documentation. Third-party code and libraries retain their original attribution.
