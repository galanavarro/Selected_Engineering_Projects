# Pacemaker Simulation Using Cardiac Cell Models

An educational electronics project exploring pulse generation and the response of electronic cardiac-cell models using TINA-TI.

## Project overview
The project studies a simplified pacemaker based on capacitor charging and discharging. Simulation results in the report examine stimulation timing, atrioventricular and ventricular model responses, capture threshold and the effect of input impedance.

## Repository contents
- `circuits/pacemaker_cardiac_model.TSC`: recovered pacemaker/equivalent cardiac model project.
- `circuits/charge_discharge.TSC`: charging/discharging circuit selected by the author; recovered from `Cargay descarga - autosave 26-01-21 19_28.TSC`.
- `report/pacemaker_simulation_report.pdf`: original Spanish-language team report, including circuit diagrams, theoretical calculations and simulation plots.

## Software
The recovered files identify TINA 9.3.200.277 SF-TI. Open `.TSC` files using a compatible TINA-TI installation. The files have been preserved without modifying their contents; they have not been opened or rerun during repository preparation. The supplied report is the record of the original analysis; exact correspondence of the recovered circuits with every reported experiment has not yet been verified.

## Analysis covered in the report
- RC charge and discharge behaviour.
- Periodic stimulation pulse generation and transient response.
- Comparison of spontaneous and stimulated model activity.
- Parameter sensitivity, including stimulation amplitude and input impedance.

## Background and attribution
Completed as a team project for Equipos de Monitorización, Diagnóstico y Terapia at Universidad Politécnica de Cartagena. The original report lists the full team and references for the cardiac models.

## Scope
This is an educational circuit simulation, not a clinically validated pacemaker or a design for use with people. Reported thresholds and responses relate to the simulated models.
